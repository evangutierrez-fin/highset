- **Allowed internal dependencies:** `highset-core`, `highset-store`, `highset-secrets`
- **Rules:** see [`docs/ARCHITECTURE.md` §2](../../docs/ARCHITECTURE.md#dependency-rules). `cargo run -p xtask -- check-deps` enforces them.
